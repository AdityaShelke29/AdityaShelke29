**What am I up to?**
- Working on scalable P2P live video streaming using WebRTC for medium-sized group calls. Traditional P2P conferencing relies on a fully connected mesh, requiring each peer to upload and download O(n) streams, which does not scale. Instead, a central signaling server coordinates a hybrid mesh topology in which peers maintain connections to a limited subset of other peers. Media streams are relayed across the mesh (e.g., A → B → C), eliminating the need for direct connections between all participants. The system dynamically adapts stream resolution and mesh structure based on peer bandwidth, enabling efficient scaling while preserving decentralized, P2P media distribution.
